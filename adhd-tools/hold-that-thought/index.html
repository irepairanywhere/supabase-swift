          One-press talk

          Claude pages can't use your microphone, but your iPhone can. Build this Shortcut once. When you run it, it starts listening right away and drops your words into Caught here.

          1. In the Shortcuts app, tap + and name the new shortcut Hold That Thought.
          2. Add Dictate Text. Set Stop Listening to After Pause.
          3. Add Base64 Encode. Tap the arrow on it and set Line Breaks to None.
          4. Add Replace Text three times, one for each row. Leave the last Replace box empty.
            FindReplace with
            +-
            /_
            =leave empty
          5. Add Random Number. Set it to between 1 and 999999999.
          6. Add Text and paste the link below into it. Then tap Random Number in the bar above the keyboard, type a dot, and tap Updated Text.
          7. Add Open URLs.

          Make it one press

          • Action Button: in Settings, open Action Button, pick Shortcut, then Hold That Thought.
          • Back Tap: in Settings, open Accessibility, then Touch, then Back Tap. Pick Hold That Thought for Double Tap.
          • Siri: say "Hey Siri, Hold That Thought."

          Test it

          Run the shortcut and say "testing one two". A few seconds later this page opens and shows "Caught from your voice".

          Turn this on only after the test works. If the orange button then does nothing when you tap it, turn this off and use the Action Button or Back Tap.
